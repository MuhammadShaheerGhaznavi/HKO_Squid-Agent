## Content
The Private Communication Network service allows authorized airline operators and local organizations to access the HKCAD ATS Messaging Handling System (AMHS) web server for message exchange via AFTN, submit flight plans for flights departing HKIA, and download PIB and NOTAM Summary. Subscription is via PCCW. Minimum equipment: a dedicated PC with web browser (e.g., Internet Explorer 7+ or Firefox 3+ with Java Runtime Environment 6) and a connection to the network. No application software installation is needed; it is downloaded on connection. Security measures: regular OS updates, anti-virus, firewall, physical access control, no internet access, and disabling other network facilities. Contact: Duty Officer at Aeronautical Network Centre, Tel +852 2910 6216, Fax +852 2910 1118; PCCW Hotline +852 2888 7180 for connection issues; PCCW +852 2888 3492 for subscription.

## Content
Seven scenarios outline actions for RVSM contingencies:
1. **Loss/degradation of all primary altimetry or inability to maintain CFL due to turbulence/loss of auto-altitude control**: Pilot maintains CFL, watches traffic, alerts nearby aircraft via lights and broadcasts on 121.5 MHz (backup 123.45 MHz), notifies ATC. Possible actions: maintain CFL if separation can be provided, request climb/descend out of RVSM, or execute contingency manoeuvre (offset track and level). Controller obtains intentions, provides separation if possible, accommodates exit, advises traffic, notifies adjoining sectors.
2. **Failure/loss of accuracy of one primary altimetry system (e.g., >200 ft difference)**: Pilot cross-checks standby altimeter, confirms accuracy, notifies ATC of loss of redundancy. If unable to confirm, follow Scenario 1.
3. **Loss of redundancy in primary altimetry systems**: If remaining system functions normally, couple to auto-altitude control, notify ATC, maintain vigilance. Controller acknowledges and monitors.
4. **Primary altimeters diverge by more than 200 ft (60 m)**: Pilot attempts to determine defective system via troubleshooting or comparing to standby altimeter. If defective system found, couple functioning altimeter to altitude-keeping device. If not, follow Scenario 5.
5. **All automatic altitude control systems fail**: Pilot maintains CFL manually, watches traffic, alerts nearby aircraft, notifies ATC. Possible actions: maintain CFL if possible, request climb/descend, or execute contingency manoeuvre. Controller assesses traffic, provides separation if possible, accommodates exit, advises traffic, notifies adjoining sectors.
6. **All primary altimetry systems unreliable or fail**: Pilot maintains CFL by reference to standby altimeter, alerts nearby aircraft, considers declaring emergency, notifies ATC. Possible actions: maintain CFL if separation provided, request climb/descend, or execute contingency manoeuvre. Controller obtains intentions, provides separation if possible, accommodates exit, advises traffic, notifies adjoining sectors.
7. **Turbulence greater than moderate affecting ability to maintain flight level**: Pilot watches traffic, alerts nearby aircraft, notifies ATC of intended course of action. Possible actions: maintain CFL if separation provided, request flight level change, or execute contingency manoeuvre. Controller assesses traffic, provides separation if possible, advises traffic, monitors, notifies adjoining sectors.
